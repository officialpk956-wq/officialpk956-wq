## 🧠 About

I turn ambiguous, messy problems — a low-resolution satellite image, a million rows of anonymous clickstream, an unread research paper — into systems that produce a clear, trustworthy answer.

My work lives across **deep learning for remote sensing**, **NLP and agentic AI**, **explainable AI (XAI)**, and **behavioral analytics at scale**. I care less about squeezing out the last 0.1% of benchmark accuracy and more about whether a model's output can be *trusted, explained, and acted on* by someone who isn't me.

> Every pipeline I build has to answer one question honestly: **can a human make a better decision because this exists?**

## 🚀 Featured Projects

<details>
<summary><b>📄 Paper2Code — from PDF to working repo</b></summary>

<br/>

An agentic pipeline that reads a research paper and produces a structured, runnable implementation — collapsing the weeks a researcher usually spends reverse-engineering someone else's method into hours.

| Aspect | Detail |
|---|---|
| **Stack** | Python, LLM Agents, Automated Code Generation |
| **Scale** | Multi-paper, cross-domain pipeline |
| **Performance** | Automated end-to-end paper → implementation translation |
| **Security** | Sandboxed code generation & execution |
| **Impact** | Cuts research-to-implementation time significantly |
| **Repository** | [github.com/officialpk956-wq/paper2code](https://github.com/officialpk956-wq/paper2code) |

The hard part isn't parsing the PDF — it's inferring the parts every paper leaves implicit: hyperparameters, data assumptions, architectural glue. This project makes those inferences explicit and reviewable, not hidden inside a black box.

</details>

<details>
<summary><b>📊 Ecommerce Funnel Analytics — 1M+ sessions, one story</b></summary>

<br/>

A session-level clickstream pipeline that turns raw event noise into a funnel a business can actually act on — where users drop off, why, and what it costs.

| Aspect | Detail |
|---|---|
| **Stack** | Python, Pandas, SQL, Matplotlib, Seaborn |
| **Scale** | 1M+ session-level records |
| **Performance** | Optimized fact-table modeling for fast funnel queries |
| **Security** | Data anonymization, safe aggregation practices |
| **Impact** | Enables funnel drop-off diagnosis and revenue forecasting |
| **Repository** | [github.com/officialpk956-wq/ecommerce-funnel-analytics](https://github.com/officialpk956-wq/ecommerce-funnel-analytics) |

Built the way a data warehouse team would: raw events → clean fact tables → funnel metrics → forecast, each layer queryable and defensible on its own.

</details>

<details>
<summary><b>🛰️ Remote Sensing Super-Resolution — MODIS to Landsat</b></summary>

<br/>

A deep learning framework that reconstructs high-resolution detail from coarse satellite imagery, sharpening the resolution gap between MODIS and Landsat for finer-grained environmental monitoring.

| Aspect | Detail |
|---|---|
| **Stack** | PyTorch, TensorFlow, OpenCV, CNN-based SR architectures |
| **Scale** | Multi-band satellite raster datasets |
| **Performance** | Improved spatial resolution while preserving spectral fidelity |
| **Security** | Reproducible, versioned data pipeline |
| **Impact** | Enhances precision of environmental and land-use monitoring |
| **Repository** | Private / research repository |

The constraint that makes this hard: you can't just upscale pixels, you have to preserve spectral truth — a sharper image that lies about surface reflectance is worse than a blurry one that's honest.

</details>
